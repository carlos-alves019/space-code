## Space Code – FP01

Este repositório contém o website institucional da **Space Code**, uma empresa fictícia de desenvolvimento de software.  
O projeto foi criado para praticar **HTML5** e **CSS3** no **Visual Studio Code**.

##  Sobre o Projeto
O site apresenta várias secções que representam uma empresa moderna de tecnologia:

- Página Inicial – apresentação da Space Code
- Projetos – mostra alguns trabalhos desenvolvidos
- Contactos – informações de contacto e redes sociais

##  Tecnologias Utilizadas
- HTML5  
- CSS3  
- Font Awesome (ícones)  
- Visual Studio Code  

##  Estrutura do Projeto

```
Space Code/
│── index.html          # Página inicial
│── projetos.html       # Página de projetos
│── contactos.html      # Página de contactos
│── css/
│     └── style.css     # Estilos do site
```

##  Funcionalidades
- Layout simples e intuitivo  
- Navegação entre páginas  
- Uso de ícones  
- Secções bem organizadas  

##  Como Executar
1. Clonar o repositório:
   ```
   git clone https://github.com/teu-utilizador/space-code.git
   ```
2. Abrir a pasta no Visual Studio Code.  
3. Abrir o ficheiro **index.html** no navegador.

##  Objetivo do Projeto
Este site foi desenvolvido com fins educativos, para praticar:

- Estruturação HTML  
- Estilização com CSS  
- Organização de projeto  
- Trabalho em ambiente VS Code
